Dialer // SignalWire Campaigns

Phase 1: outbound calling only. A campaign dials calendar leads / filtered Sheet leads / pending silo candidates from a local-presence number pool. With a pitch recording set, an answered call plays it and waits for a keypress: "1" bridges straight to that campaign's follow-up number, anything else ends the call politely. No pitch recording set = bridges immediately on answer. The recording is a real recording of you pitching, not a synthetic/AI voice -- deliberate, see the compliance notes this was built from. After each call, mark it Advance (converts a silo candidate into Master Log V2, or moves an existing lead forward) or Purge (dismisses/ghosts it) -- same disposition path the Targets grid's Convert/Dismiss buttons already use. Not yet built (deferred, not silently skipped): concurrent inbound campaigns, SMS/10DLC, and real predictive volume pacing -- "max calls per run" below is a manual batch cap, not an optimizer. Run several campaigns with different caller_connect_number values (your different phones) to work multiple lines at once.
